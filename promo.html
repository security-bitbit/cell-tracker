기능 01 SKT · KT · LGU+ 3사 통합

통신사별 기지국 문자 양식 100% 자동 분석

통신사마다 제각각인 기지국 위치추적 문자 양식을 자동으로 판별하여 전화번호, 기지국 PCI, 확인 일시, 단말기 상태(켜짐/꺼짐), 주소를 즉시 추출해 지도에 표시합니다.

▼ 자동 분석 예시
[281]010-1234-5678[1118-18:00]위치확인-인천 계양구 계산새로 68
PCI: 281 번호: 5678 일시: 11/18 18:00 주소: 인천 계양구 계산새로 68
기능 02 현장 수색 범위 압축

내 휴대폰 실시간 PCI 스캔 및 현위치(GPS) 표시

낯선 현장에 출동했을 때 🧭 버튼을 누르면 지도 위에 내 현재 위치(GPS)가 파란색 레이더 점으로 실시간 표시됩니다. 또한 현재 내 스마트폰이 잡고 있는 기지국 PCI 값을 3초마다 스캔하여 대상자의 PCI와 일치하면 (🎯일치!) 알림을 띄워줍니다.

💡 통신망 및 알뜰폰(MVNO) PCI 비교 안내
• 동일 위치라도 통신망(SKT·KT·LGU+)이 같아야 동일한 PCI 값이 표시됩니다.
• 별정통신사(알뜰폰)는 브랜드와 관계없이 실제 임대해 사용하는 모회사 통신망(SKT망 알뜰폰=SKT, KT망 알뜰폰=KT, LGU+망 알뜰폰=LGU+)과 100% 동일한 PCI 값을 표시합니다.
기능 03 동선 겹침 방지

체류 시간 자동 합산 & 공범·가족 번호 스마트 분리

대상자가 한곳에 머물러 동일 PCI 문자가 여러 번 와도 마커가 지저분하게 겹치지 않고 "18:00 ~ 18:25 (25분째 체류중)"으로 깔끔하게 합산됩니다. 여러 대의 전화번호를 동시에 추적할 때는 고유 색상별로 동선이 나뉘며, 뒷자리(`5678`)가 같은 가족·공범 번호가 들어오면 자동으로 앞자리까지(`1234-5678`, `0000-5678`) 구분해 표시합니다.

ANDROID 전용

📲 아르고스(ARGUS) APK 설치 및 권한 설정 안내

아르고스는 플레이스토어·갤럭시스토어 등 외부 스토어를 거치지 않고 전용 설치 파일(APK)로 배포됩니다. 설치 전 아래 순서대로 설정을 확인해 주세요.

📥 아르고스 안드로이드 APK 다운로드
STEP 1. 갤럭시 '보안 위험 자동 차단' 해제 (설치 전 필수)

안드로이드는 플레이스토어·갤럭시스토어 등 공식 경로가 아닌 앱의 설치를 기본 차단하고 있습니다.
스마트폰 [설정] ➔ [보안 및 개인정보 보호] ➔ [보안 위험 자동 차단]을 꺼짐(OFF)으로 바꾸어야 APK 설치가 가능합니다.

STEP 2. '인증되지 않은 출처의 앱' 안내창에서 [무시하고 설치] 선택

다운로드한 APK 파일을 실행하면 '인증되지 않은 출처의 앱'이라는 보안 안내창이 뜹니다. 해당 창에서 바로 [무시하고 설치]를 눌러 설치를 완료해 주세요.

STEP 3. 앱 최초 실행 시 권한 허용 안내

어플을 처음 켤 때 위치(GPS) 권한과 알림 허용 권한을 허용할 것인지 묻는 알림창이 자동으로 뜹니다. 그때 모두 [허용]을 눌러주시면 실시간 문자 자동 인식과 내 위치·PCI 표시가 정상 작동합니다.
